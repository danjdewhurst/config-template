# Infra

My infrastructure is documented in the config repo at `~/Projects/config`.

1. Read `~/Projects/config/AGENTS.md` first. It has the overview, how to reach each machine, and the rules for agents.
2. Read the machine or network file it points to for the task at hand.
3. Follow the rules in `AGENTS.md`: check live state before trusting the notes, ask before changing a server, never store secrets, and update the notes when they're wrong.
